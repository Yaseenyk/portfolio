# Remote Job Hunt — Platform Playbook

**Goal:** land a remote / WFH role as a Senior Full-Stack AI Engineer.
**Reality:** the platform is only the funnel. What wins is **(1) a complete,
consistent profile everywhere + (2) volume + (3) referrals.** Spraying an
incomplete profile across 30 sites does nothing. Fill each properly, then apply.

---

## 0. How to use this doc

1. Fill in the **Master Profile Pack** below once.
2. Paste that same data into every platform (consistency = a stronger "you"
   across the web and in recruiter searches).
3. Work the platforms **top-down** — Tier 1 first (highest ROI). Don't touch
   Tier 4 until Tier 1–2 are fully set up and you're applying daily.
4. Track every application in the tracker at the bottom.

## 2. Tier 1 — Must-do (highest ROI, set up this week)

### LinkedIn — https://www.linkedin.com
The single most important platform. Recruiters live here.
- **Feed it:** headline, About (long bio), Experience (mirror the resume,
  bullet-per-achievement), Skills (top 3 pinned: AI Engineering, React, Node),
  Featured section (pin portfolio + Sable case study + resume PDF), profile
  photo + banner.
- **Turn on "Open to Work"** → set job titles (AI Engineer, Full-Stack Engineer,
  ML Engineer), **location type = Remote**, start date. Use the "recruiters only"
  visibility if your current employer might see it.
- **Custom URL:** already `/in/yaseen-yk` — good.
- **Do weekly:** post one build-in-public update (Sable, the AI Blogger). Inbound
  from founders starts here.

### Wellfound (formerly AngelList Talent) — https://wellfound.com
Best for startup + remote roles; startups value shipped products over pedigree.
- **Feed it:** full profile, "Remote" preference, desired role + salary, link
  portfolio + GitHub, list all flagship projects, mark **actively looking**.
- Apply directly to remote-tagged roles; founders often DM back.

### We Work Remotely — https://weworkremotely.com
Largest remote-only job board.
- **Feed it:** apply per listing with a tailored top line + resume link. No
  profile to build — it's a board. Filter "Programming".

### Remote OK — https://remoteok.com
High-volume remote board, dev-heavy.
- **Feed it:** apply per listing. Set up email alerts for "AI", "React",
  "Full-Stack".

### Y Combinator — Work at a Startup — https://www.workatastartup.com
One profile → apply to hundreds of YC startups, many remote/global.
- **Feed it:** full profile, remote preference, projects, GitHub. YC founders
  contact you directly. High signal for AI startups.

### Hacker News "Who is Hiring" — monthly thread on https://news.ycombinator.com
Posted 1st of each month. Ctrl-F "remote" + "AI".
- **Feed it:** reply/apply per post as instructed; no profile. Excellent for
  remote-first startups.

## 10. Weekly cadence (this is what actually lands the job)

- **Daily:** 5 tailored applications (customize the first line to the company).
- **Daily:** 2 referral touches — DM a 2nd-degree connection or engineer at a
  target company. Referrals convert ~10× a cold apply.
- **2×/week:** one build-in-public post (LinkedIn + X) about Sable / AI Blogger.
- **Weekly:** refresh Naukri + LinkedIn activity; review the HN "Who's hiring"
  thread on the 1st.
- **Ongoing:** keep a target list of 30–50 AI-first remote companies; apply
  direct + hunt a referral for each.

### Priority order if you only do a few things
1. **LinkedIn** — fully optimized + Open to Work (Remote)
2. **Wellfound + Work at a Startup** — one profile, huge reach
3. **We Work Remotely + Remote OK** — daily applications
4. **Turing / Arc.dev** — vetted inbound for India-based remote
5. **Referrals** — every day, non-negotiable

_Everything else compounds on top. Volume + referrals + a shipped-product story
(Sable) is the winning combination._
