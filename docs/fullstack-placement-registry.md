# Full-stack placement registry

Compiled 2026-10-22. One job: get into the database of every firm that places
full-stack developers, local and international, whoever pays.

Each row says **who pays** (employer, you, or you-after-placement), the **fee**
as the firm publishes it, and the **registration link**. Every link was fetched
and returned `200` on the date above. Firms whose site blocked automated
reading are in §9 rather than carried with a guessed link.

The supporting detail (what each firm is, how to follow up, scam warnings)
lives in `consultancy-outreach-list.md`. This file is the checklist.

## 8. Overseas agents

Not a list on purpose. An agent recruiting Indians for jobs abroad must hold an
MEA Recruiting Agent licence; check it on https://emigrate.gov.in/. The legal
maximum fee is **₹30,000 + 18% GST**. IT roles are not emigration-check-
required, so the Gulf and Europe agencies in §3 and §4 are the route, and they
are free.
