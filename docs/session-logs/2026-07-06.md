## 1. GSC "Couldn't fetch" — diagnosed & fixed
- **Symptom:** Google Search Console showed "Couldn't fetch" for the sitemap for ~a month, on both GitHub-hosted projects.
- **Root cause:** the portfolio was a GitHub **project site** served under a subpath (`yaseenyk.github.io/portfolio/`). Submitting `/sitemap.xml` (leading slash) made Google fetch the **host root** `yaseenyk.github.io/sitemap.xml` → 404. The real file at `/portfolio/sitemap.xml` was fine (verified 200). Same failure hit both GitHub project sites (shared host root); domain-hosted projects worked because they serve at root.
- Confirmed server-side was healthy (200, `application/xml`, valid XML, robots permits). The GSC "something went wrong" popups were Google's own tooling glitches, not our site.
